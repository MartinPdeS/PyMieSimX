Sharing simulations
===================

Use **Copy simulation link** in Single scatterer, Parameter scan, or Ensemble
optics to share the current setup. A link contains the configuration, sweep
ranges, selected measures, and plot settings; it does not contain a snapshot of
the computed result.

When a link is opened, PyMieSimX restores the inputs and recalculates the
simulation with the installed PyMieSim and PyOptik versions. Results can change
when those dependencies or material data are updated. Use **Run** after editing
any restored value.
